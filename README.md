# Winter Summit Planner

A single-page tool comparing car-free New Year mountain trips (30 Dec 2026 – 5 Jan 2027, or 2 – 6 Jan 2027) for a group leaving from Paris, Strasbourg, Berlin and Chișinău.

Destinations: Zakopane (PL), High Tatras – Starý Smokovec / Tatranská Lomnica (SK), Sinaia / Bușteni (RO) and San Candido / Innichen, Alta Pusteria (Dolomites, IT).

Open `index.html` in a browser. Set travellers per city, pick the dates, weight your priorities, and type real housing quotes to replace the estimates. All prices are estimates compiled in September 2026.
